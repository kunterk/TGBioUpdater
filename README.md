# 🎵 TGBioUpdater

Automated real-time Telegram Bio Updater synced with Last.fm now playing tracks. Built with Pyrogram & Render integration.

## 🚀 One-Click Deploy
Click the button below to deploy your instance to Render:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/kunterk/TGBioUpdater)

## 🛠️ Environment Variables
| Variable | Description |
|---|---|
| `API_ID` | Telegram API ID |
| `API_HASH` | Telegram API Hash |
| `LASTFM_API_KEY` | Last.fm API Key |
| `LASTFM_USERNAME` | Last.fm Username |
| `SESSION_STRING` | Pyrogram String Session |
| `GUIDE_BOT_TOKEN` | BotFather Token for Guide Bot |
